# AI Trading Assistant Platform

Персональная AI-платформа для трейдинга, разрабатываемая по принципу
**Architecture First → Documentation First → Code Last**.

## Статус проекта

Проект находится на этапе формирования устава и инженерной документации.
Реализация кода не начата — она начнётся только после утверждения архитектуры.

## Роли

- **Product Owner** — определяет продуктовые требования и приоритеты.
- **Solution Architect / CTO (ChatGPT)** — принимает архитектурные решения.
- **Senior Software Engineer (Claude)** — реализует задачи в рамках утверждённой архитектуры.

Подробное описание миссии, целей, ролей и правил проекта — в [PROJECT_CHARTER.md](./PROJECT_CHARTER.md).
